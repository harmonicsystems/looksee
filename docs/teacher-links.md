# One bookmark for each part of the day

For the classroom Chromebook. Open each link, then bookmark it (the star in the address bar,
or Ctrl + D). Each bookmark is named for you, so the bookmarks bar reads like the day. One click
on a bookmark switches the screen to those words; the Play button starts them.

- A change made while a bookmark is open (Spanish words, slower slides) is not saved into the

  will appear under Tools ▸ Watch with these words around them.
